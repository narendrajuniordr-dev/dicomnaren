Viewer DICOM

Buka file .zip, file .dcm, atau folder hasil ekspor (Horos dll).

File diproses di perangkat ini saja, tidak diunggah ke mana pun.
Mendukung DICOM tidak terkompresi, JPEG Lossless, dan RLE (CT, MRI, CR/DX). Di komputer bisa juga seret-lepas file/folder ke sini.

Tanya Claude
Belum ada slice. Pilih panel, cari slice penting, lalu tekan "Tandai slice aktif" (atau tombol K).
Lihat / ubah template terpilih (tersimpan di browser ini)
Aturan umum gaya bacaan
Mode kirim manual: viewer ini tidak terhubung ke akun Claude. Tombol Bagikan ke Claude menyiapkan gambar + teks permintaan, lalu pilih aplikasi Claude di lembar bagikan. Jika teks tidak ikut terbawa, teksnya sudah otomatis tersalin — tinggal tempel (paste) di Claude.
Nama/ID pasien tidak ikut dikirim, tetapi gambar tetap dikirim ke Claude. Hasil adalah draf AI dari slice terpilih saja — wajib diverifikasi dokter dan bukan pengganti pembacaan seluruh studi.
Daftar pasien
Pasien yang terbuka disimpan sementara di browser HP ini (maks. 24 jam) agar tidak hilang saat layar dilipat/dibuka. Hapus (×) pasien yang sudah selesai agar memori dan penyimpanan tetap lega. Geser panel ke kiri untuk menutup. Di komputer: klik-tahan lalu seret panel ke kiri untuk menutup.
Catatan
Catatan tersimpan otomatis per pasien di perangkat ini saja, dan ikut terhapus saat pasien dihapus (×) atau setelah 24 jam.
