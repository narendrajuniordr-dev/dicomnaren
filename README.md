# dicomnaren — Viewer DICOM

Dibuat oleh / Created by: **narendrajr**

## Ringkasan (Bahasa Indonesia)

Viewer DICOM ringan berbasis web yang dibuat untuk **kebutuhan dasar dan cepat** dalam membaca pemeriksaan radiologi, berdasarkan pengalaman sehari-hari sebagai dokter spesialis radiologi. Viewer ini dirancang agar bisa dipakai di HP, tablet, maupun komputer, termasuk tanpa internet, untuk melihat studi CT dan MRI dengan cepat tanpa perlu memasang aplikasi workstation.

Fitur utama:
- Membuka file DICOM, folder, atau zip (tidak terkompresi, JPEG Lossless, RLE)
- Tampilan 2D, MPR (aksial, koronal, sagital) dengan garis silang, dan mode banding beberapa seri/sequence MRI
- Preset window (soft tissue, paru, tulang, otak, dll.), slab MIP/MinIP
- Ukur jarak, densitas HU satu titik, dan ROI (rerata, SD, min/maks, luas)
- Daftar beberapa pasien, catatan per pasien dengan template bacaan, dan shortcut keyboard

Semua file diproses **di perangkat pengguna sendiri** dan tidak diunggah ke server mana pun.

## Summary (English)

A lightweight, web-based DICOM viewer built for **basic and fast** review of radiology studies, based on daily clinical experience as a radiologist. It runs on phones, tablets and computers, including offline, so CT and MRI studies can be viewed quickly without installing a full workstation application.

Main features:
- Opens DICOM files, folders or zip archives (uncompressed, JPEG Lossless, RLE)
- 2D view, MPR (axial, coronal, sagittal) with crosshair, and side-by-side comparison of multiple series/MRI sequences
- Window presets (soft tissue, lung, bone, brain, etc.), MIP/MinIP slab
- Distance measurement, single-point HU density, and ROI (mean, SD, min/max, area)
- Multiple patients list, per-patient notes with reading templates, and keyboard shortcuts

All files are processed **locally on the user's own device** and are never uploaded to any server.
